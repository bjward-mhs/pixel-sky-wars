# pixel-sky-wars

Pixel Wars is a browser-based pixel dogfight campaign.

## Current Version

**0.7.0 - Frontline Artillery Build**

The in-game build badge and briefing panel are the source of truth for the current version. Version history is kept in `game.js` so each published build can show its update summary.

### Version History

- **0.7.0** - Added captureable trench lines, team-aware soldiers, destructible artillery, and artillery mode.
- **0.6.0** - Added campaign weather and the first rainy terrain prototype.
